PHOTOS OF YOU GO IN THIS FOLDER
===============================

Two files are referenced in content.json:

  headshot.jpg  -> the portrait in the hero at the top of the page
                   set in content.json under "profile" > "photo"
                   portrait orientation works best (roughly 4:4.4)
                   about 900 x 1000 pixels

  about.jpg     -> the photo beside the About text
                   set in content.json under "about" > "photo"
                   portrait orientation (roughly 4:5)
                   about 900 x 1125 pixels

Keep each file under 400 KB. Free resizer: squoosh.app

If a file isn't here yet, the site shows a neutral placeholder instead of a
broken image, so you can deploy first and add photos later.
