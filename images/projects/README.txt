PROJECT PHOTOS GO IN THIS FOLDER
================================

1. Drop your photo files right here (this folder: images/projects/).
2. Open content.json and put the file name in the project you want it on.

   Cover photo (the one on the card):     "coverPhoto": "mazda3-cover.jpg"
   Gallery photos (on the detail page):   "photos": [
                                            { "file": "mazda3-01.jpg", "caption": "Front end reassembled" },
                                            { "file": "mazda3-02.jpg", "caption": "Tapped manifold ports" }
                                          ]

NAMING
  Use lowercase letters, numbers and hyphens only. No spaces, no #, no ( ).
  Good:  mazda3-01.jpg      fuel-pump-adapter-cover.jpg
  Bad:   IMG_2841 (1).JPG   My Photo #2.jpg

SIZE
  Cover photos:  about 1600 x 1000 pixels
  Gallery:       about 1600 pixels on the long edge
  Keep every file under 400 KB so the site stays fast.
  Free resizer: squoosh.app  (drag photo in, drop quality to ~70%, download)

FORMAT
  .jpg for photographs, .png for screenshots and drawings, .webp if you have it.

Until a photo exists, the site shows a neutral "Image pending" placeholder
instead of a broken image. Nothing breaks if you leave this folder empty.
